# [Rollidy](https://hyperagon.github.io/projects/rollidy/)
### Rolling Melody

- You can drag the *HTML* files to your browser.
- Hold **Play** to get a panel to *Import* and *Export*
- Check out [examples](https://github.com/hyperagon/Rollidy/tree/main/songs)
- It can import [Hexano](https://github.com/hyperagon/Hexano) melodies (.json files)
